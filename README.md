# A股与全球市场选股台

沪深京 A 股全市场（5500+ 只）和 29 个世界指数、1275 只海外成分股的研究型网页。页面由 GitHub Actions 自动更新并发布到 GitHub Pages；在浏览器里打开时会自动切换为腾讯实时行情（全球指数每 5 秒、打开的个股每 5 秒刷新）。

**仅供研究参考，不构成投资建议。市场有风险，决策需独立判断。**

## 选股页

按《A股选股提示词大全》第二部分的 D 型和 F 型执行：

- **D 型 · 科技成长**：半导体、AI 算力、软件、通信、机器人、创新药、高端装备、新材料八个方向，研发投入占营收 ≥10%，排除纯蹭概念、近一年翻倍但业绩没实质增长、大股东和高管持续减持；表格列与文档一致，附题材真伪鉴别。
- **F 型 · 短线波段**：第 1 步市场情绪（成交额、涨跌家数、涨跌停、连板高度、炸板率、昨日涨停股今日表现）→ 第 2 步主线题材（主线 / 一日游、龙头、中军）→ 第 3 步个股筛选（放量突破或沿 5 日、10 日均线上行，换手 5%–20% 且有持续性，剔除 ST、减持、解禁、业绩暴雷）→ 第 4 步交易计划 → 第 5 步按情绪阶段给仓位。
- 两型都可以复制文档原文提示词（可附本站数据）给联网 AI，或直接让 DeepSeek 用本页数据分析；F 型按文档建议先做第 1-2 步，确认后再继续第 3-5 步。
- 涨跌停按交易所规则计算（前收盘 ×（1 ± 涨跌幅）四舍五入到分；新股上市初期没有涨跌幅限制，不算涨停）。

## 资金监控页

- **每日选股**：剔除 ST、次新股、成交额太小、近 20 日已大涨、未来 30 天解禁、近 30 天减持、业绩亏损或大幅下滑的股票，按主力资金（占成交额、金额、连续流入天数、5 日累计占流通市值）、盘口异动（火箭发射、大笔买卖、封涨停、高台跳水等）、龙虎榜和量比打分。分“强势异动”和“资金吸筹”两类，满 45 分的各取最多 4 只、同一行业最多 2 只（核心入选，监控池快满时少选、每天至少 3 只）；监控池不足 30 只时，两类轮流从 35 分以上的补充到 30 只。监控池保持 30–50 只（含观察期），超过 50 只时观察期里观察最久的提前移出。
- **评分**：满分 100（龙虎榜净买入 +10、净卖出 −10）。强势异动 = 当日主力占成交额 25 + 当日主力净流入 20 + 连续流入天数 15 + 5 日主力占流通市值 15 + 盘口异动 15 + 量比 5；资金吸筹 = 连续流入天数 30 + 5 日主力占流通市值 25 + 5 日主力占成交额 20 + 当日主力占成交额 15 + 盘口异动 10。入选评分固定，“今日评分”每天按最新数据重算，页面显示每一项的得分。
- **每只股票的详细信息**：资金流入流出明细（特大单、大单、小单、散单的流入、流出、净额和成交占比）；主力控盘（东方财富千股千评：机构参与度、主力买入占成交、主力成本）；持股结构（十大流通股东合计、十大以外的流通股、机构持股、股东户数和户均持股、实际控制人，季度数据）；散户占比（小单和散单成交占比、十大以外持股）；筹码分布图（按近 250 个交易日日K和换手率估算，含获利盘、平均成本、90%/70% 筹码区间和集中度、主峰）和文字分析；龙虎榜买入、卖出前 5 名席位和金额。
- **今日龙虎榜席位**：哪个席位买了哪只股票、多少钱（净买入前 40、净卖出前 20），机构专用、沪深股通、营业部分别合计，以及同一营业部当天买入的多只股票。
- **主力净流入 / 净流出前 30**：收盘后数据，交易时段每 2 分钟刷新为实时。
- **监控**：每天更新入选股票的主力资金、涨跌、异动、龙虎榜、公告和新闻。主力放弃（连续 3 日流出且吐出入选后流入的一半、放量大跌出货、连续 2 日收在 20 日线下方且流出、龙虎榜机构净卖出、盘中大笔卖出明显多于买入），或者出现利空公告、较入选价跌 12%、入选满 10 天资金热度消退时，进入观察期。之后再观察 5 个交易日：主力回流（连续 2 日净流入且站上 10 日线）就恢复跟踪，否则移出并记录区间表现。
- **重点提醒**：观察期、风险、移出、新入选、主力回流、龙虎榜、利好公告按重要程度排列；交易时段另有“盘中实时”提醒（主力大幅流出或流入、跌破 20 日线、大跌）。
- **近期信息**：点开任意一只股票（不只是监控池里的），都会实时获取近 40 个交易日的主力资金、资金流入流出明细、千股千评、十大流通股东和股东户数、筹码分布、龙虎榜席位、当天盘口异动、最新公告和新闻，并可以让 DeepSeek 做全面调查（保存到 AI 历史记录）。
- 每天的完整监控状态另存为网页旁边的 `flow.json`；数据缓存丢了时自动从这里取回，监控不中断。

GitHub 的定时任务是“尽力而为”，高峰期可能晚几分钟到几十分钟，偶尔会跳过一轮。

## 第一次配置（约 3 分钟）

1. **开启 Pages**：Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。不要选 Deploy from a branch：那样每次提交时 GitHub 会把 README 发布成网页，盖掉选股台。
2. **添加 DeepSeek Key（可选）**：Settings → Secrets and variables → Actions → New repository secret，Name 填 `DEEPSEEK_API_KEY`，Value 填你的 key。不填也能运行，研判部分会显示原有的人工文字。
3. **手动跑第一次**：Actions → 更新数据并发布网页 → Run workflow（`force` 填 `1` 表示全部重新抓取）。第一次约 8 分钟，之后每小时一轮约 1～2 分钟。
4. 打开 `https://<你的用户名>.github.io/stock-desk/`，在手机上可用 Safari / Chrome 的「添加到主屏幕」。

## 网页里的 AI（选股助手、个股和指数分析）

网页是公开的，所以 key 不能写进网页文件。打开网页 → 「AI 助手」→「DeepSeek 设置」，粘贴你的 DeepSeek API Key，点「保存并验证」。Key 只保存在这台设备的这个浏览器里，只发给 `api.deepseek.com`；换手机、换浏览器或从 iPhone 主屏幕图标打开时需要再填一次。建议为网页单独建一个 key，不用时在 DeepSeek 后台删除。

上面第 2 步的仓库 Secret 只给 GitHub Actions 生成每日研判用，网页读不到它。

## 本地运行

```bash
pip install -r requirements.txt
export DEEPSEEK_API_KEY=...        # 可选
python scripts/build.py            # 生成 site/index.html
FORCE=1 python scripts/build.py    # 全部重新抓取
ONLY=market,news python scripts/build.py   # 只跑指定任务
```

## 目录

- `scripts/build.py`：排程入口，按各任务周期决定刷新什么，任何一项失败都沿用缓存
- `scripts/a_share.py`、`global_mkt.py`、`lists.py`、`news.py`、`ai_commentary.py`、`gen.py`：各数据模块与网页生成
- `template.html`：网页模板（图表引擎、指标、分时、全球市场、AI 助手）
- `seed/`：全球指数历史种子，缓存为空且 Yahoo 访问不到时使用
- `data/`、`site/`：运行时生成，不进 git（数据通过 Actions 缓存在两次运行之间保留）

## 已知限制

- 印度、澳洲、新加坡、瑞士指数的实时报价和部分海外指数的实时分时依赖东方财富，在部分网络下访问不到时用快照加 5 秒报价。
- 日本、欧洲、印度、韩国个股没有浏览器可直接访问的免费实时接口，网页里显示最近一次更新的快照。
- 俄罗斯、泰国、越南指数没有免费历史数据，只有报价。
- AI 研判由模型自动生成，只引用页面提供的数据和快讯标题，可能有误；请以原始公告和数据为准。
